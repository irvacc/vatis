# Iran vACC - vATIS Profile

This repository contains the official vATIS profile for the Iran vACC. It is designed for use by controllers within the Tehran FIR (OIIX).

## Installation & Usage

1.  **Download**: Go to the **[Releases](../../releases)** section of this repository.
2.  **Get the File**: Download the latest `oiix.json` file from the release assets.
3.  **Import**: Open your vATIS software and use its import function to load the downloaded `oiix.json` file.
4.  **Apply**: Select the profile for your controlling position.

## Support
